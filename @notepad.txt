

- request help
	- request components: human resources, money, materials
	- requester can expire request components or an entire request
	- request is marked as fulfilled when done
	- fulfilled and expired items cannot be delivered again
	
- response to help
	- anyone can respond to a request (partially or entirely)
	- response sent to the relief center
	- pledge: response made before an event, delivered at event time

- site users
	- need authentication for asking for contributions
	- query and match request they want to respond to and deliver

- call center
	- connect people who need help, people who want to help, volunteers, and government agencies
	- operator and admin users

- disasters
	- geographic location details
	- contact center details
	- duration of occurrence of event
	- categories of required items or help (created by admins)
	- existing events can have required items added by any user from the event center or administrator
	- categories of items differ for different events
	- common attributes of each item are listed
	- confidentiality of volunteers must be maintained
	- email confirmation is required
	- context-sensitive help text, users should be able to change it
	- ability to change/cancel a requirement or offer for help
	- system administrators can do any of the functions
	- user feedback, ranking on condition of resource

- other requirements
	- optimization of travel distance
	- web portal supports concurrency
	- web and mobile application
	- email notifications

- data model
	- search for requirements at relief center near their zip code
	- efficiency: people near disaster location provide help
	* mysql or oracle or sql server for database

- security
	- data encryption (128 bits)
	- invisible password
	- structure of password
	- password change policy
	- user id/password retrieval


- other technical requirements:
	- backend: java, .net, python
	- use MVC/REST or something similar
	- "508 compliant" UI; accessibility features for disability people
	- one/two meetings per week, record details
	- automated testing (junit, ...)
	- Iteration plan submission identifying functions to be delivered


	


* requests come from a location, responders may not know location or what is required
* call center connects donors, recipients, volunteers, and government agencies
